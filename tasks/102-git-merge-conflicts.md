# Aufgabe 102 — Git-Konflikte

## Ziel
Nutzer bei konkurrierenden Änderungen unterstützen, ohne Dateien zu überschreiben.

## Ergebnis
Konfliktübersicht, betroffene Abschnitte und kontrollierte Auswahl.

## Fertig, wenn
- Konflikt nicht still „gelöst“ oder als fertig markiert wird.
- Zusammenführung vor Speicherung geprüft wird.

## Schutz
Originalstände erhalten, bis Nutzer Lösung bestätigt.
