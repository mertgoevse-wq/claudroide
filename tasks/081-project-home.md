# Aufgabe 081 — Projektübersicht

## Ziel
Projektstatus und sichere nächste Schritte auf einer Smartphoneansicht zeigen.

## Ergebnis
Projektname, Ordner, letzte Arbeit, Änderungen, offene Freigaben und Tests.

## Fertig, wenn
- Widerrufene Ordnerrechte deutlich markiert sind.
- Keine Dateien ohne Auswahl automatisch gescannt werden.

## Schutz
Geheimnisse und vollständige Dateiinhalte nicht in Übersichtsvorschau anzeigen.

## Skill
Global einen Mobile-Projektübersichts-Skill suchen; Lizenz/Quelle prüfen und vor Installation Nutzer fragen.
