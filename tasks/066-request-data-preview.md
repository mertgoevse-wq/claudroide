# Aufgabe 066 — Übertragene Daten prüfen

## Ziel
Vor einer Projektanfrage zeigen, welche Dateien oder Ausschnitte an welchen Anbieter gehen.

## Ergebnis
Vorschau mit Dateinamen, Auszügen, Empfänger, Ausschlüssen und Senden-/Abbrechen-Wahl.

## Fertig, wenn
- Nutzer einzelne Inhalte entfernen kann.
- Anhänge und Bilder ebenfalls aufgelistet werden.

## Schutz
Vorschau selbst speichert keine unnötige Kopie der Inhalte.

## Skill
Global einen Datenschutz-/Datenfluss-Skill suchen, Quelle/Lizenz prüfen und vor Installation fragen.
