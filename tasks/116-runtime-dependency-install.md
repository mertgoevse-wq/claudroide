# Aufgabe 116 — Projektwerkzeuge installieren

## Ziel
Abhängigkeiten nur bewusst, mit Größe, Quelle und Folgen installieren.

## Ergebnis
Paketname, Herkunft, Lizenz, benötigter Speicher, Netzwerkzugriff und Entfernen erläutern.

## Fertig, wenn
- Nutzer Download und Installation einzeln bestätigen kann.
- Fehler keinen halbfertigen Zustand verbergen.

## Schutz
Keine ungeprüften Pakete aus beliebigen Quellen automatisch installieren.

## Skill
Global einen Supply-Chain-/Abhängigkeitssicherheits-Skill suchen; Quelle, Lizenz und Rechte prüfen, Nutzer vor Installation fragen.
