# Aufgabe 096 — Repository laden

## Ziel
Projekt von GitHub oder kompatiblem Git-Server auf das Gerät holen.

## Ergebnis
Adresse, Zielordner, Zugang, Speicherbedarf, Download-Fortschritt und Fehlerbehandlung.

## Fertig, wenn
- Nutzer vor Download Ziel und Projektquelle sieht.
- Abgebrochener Download keine scheinbar vollständige Arbeitskopie hinterlässt.

## Schutz
Repository-Inhalte als nicht vertrauenswürdig behandeln.

## Skills (aus skill-matrix.md)
Bei Ausführung **beide** Skills tatsächlich laden und ihre Verwendung im Checkpoint (`progress/BUILD-STATE.md`) notieren. Fehlt einer, nach CLAUDE.md ersetzen statt zu raten.
Global einen Git-Repository-Skill suchen; Quelle/Lizenz und Sicherheitsrisiken prüfen, vor Installation Zustimmung einholen.
