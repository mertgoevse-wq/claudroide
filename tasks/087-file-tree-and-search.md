# Aufgabe 087 — Dateien finden

## Ziel
Projektdateien durchsuchen, ohne das Gerät mit unnötigen Scans zu belasten.

## Ergebnis
Dateibaum, Suche, Ausschlussfilter und Ladezustand.

## Fertig, wenn
- Versteckte Dateien und große Ordner nach Regeln behandelt werden.
- Suche auf widerrufenen Bereichen sofort endet.

## Schutz
Dateiinhalte werden bei lokaler Suche nicht an Anbieter übertragen.

## Skill
Global einen lokalen Code-Such-Skill suchen; Quelle/Lizenz und Datenfluss prüfen, vor Installation Zustimmung einholen.
