# Aufgabe 104 — Git-Netzwerkfehler

## Ziel
Abbruch beim Laden oder Senden von Git-Daten nachvollziehbar behandeln.

## Ergebnis
Wiederaufnahme, Statusprüfung, Konflikterkennung und klare Meldung.

## Fertig, wenn
- Wiederholen keine doppelten Commits oder ungewollten Uploads verursacht.
- Nutzer sieht, welche Daten bereits übertragen sein könnten.

## Schutz
Erneuter Upload erfordert bei unklarem Zustand Bestätigung.

## Skill
Global einen Git-Netzwerk-/Sicherheits-Skill suchen; Quelle/Lizenz prüfen und Installation nur nach Zustimmung.
