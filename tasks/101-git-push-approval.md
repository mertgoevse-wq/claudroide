# Aufgabe 101 — Git-Upload freigeben

## Ziel
Nutzer sieht Repository-Ziel und Änderungsliste vor einem Upload.

## Ergebnis
Bestätigungsansicht mit Zieladresse, Zweig, Commit, Dateien und Abbrechen.

## Fertig, wenn
- Upload an privates, eingerichtetes Ziel geht.
- Fehler und Teilübertragung klar erkennbar sind.

## Schutz
Kein Push ohne ausdrückliche Freigabe und Geheimnisprüfung.

## Skill
Global einen Git-Push-/GitHub-Sicherheits-Skill suchen; Quelle/Lizenz prüfen und Installation vom Nutzer bestätigen lassen.
