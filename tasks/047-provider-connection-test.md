# Aufgabe 047 — Verbindung testen

## Ziel
Fehler bei Anbieteradresse, Schlüssel oder Modell vor einer längeren Anfrage sichtbar machen.

## Ergebnis
Kleine, klar abgegrenzte Testanfrage mit Ergebnis, Anbieter und Modell.

## Fertig, wenn
- Testdaten keine Projektdateien oder Geheimnisse enthalten.
- Kosten/Abrechnung für den Test erklärt sind, sofern relevant.

## Schutz
Keine Weiterleitung an unbekannte Adresse ohne ausdrückliche Auswahl.

## Skill
Global einen API-Test-/Netzwerksicherheits-Skill suchen; Quelle und Lizenz prüfen, Installation durch Nutzer bestätigen lassen.
