# Aufgabe 037 — Code und Antworten anzeigen

## Ziel
Codeblöcke und längere Antworten auf Smartphonebreite lesbar darstellen.

## Ergebnis
Formatierung, horizontales Scrollen wo nötig, Codekopieren und lange Inhalte einklappen.

## Fertig, wenn
- Code unverändert kopiert werden kann.
- Formatierungsfehler die Originalantwort nicht zerstören.

## Schutz
Angezeigter Code wird nicht automatisch ausgeführt.

## Skill
Global einen Markdown-/Codeanzeige-Android-Skill suchen; Lizenz und Sicherheitslage prüfen, Installation bestätigen lassen.
