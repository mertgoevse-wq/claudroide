# Aufgabe 099 — Aufgabenstand sichern

## Ziel
Zusammengehörige, geprüfte Änderungen als benannte lokale Stände speichern.

## Ergebnis
Commit-Vorschlag, Dateiübersicht, Prüfstatus und Änderungsverlauf.

## Fertig, wenn
- Commit-Nachricht den Zweck verständlich beschreibt.
- Nutzer Änderungen vor dem Speichern einsehen kann.

## Schutz
Keine unbestätigten oder geheimnishaltigen Dateien einschließen.

## Skill
Global einen Git-Commit-/Secret-Scan-Skill suchen; Quelle/Lizenz prüfen und Nutzer vor Installation fragen.
