# Aufgabe 108 — Freigabestufen

## Ziel
Vorsichtige, ausgewogene und weniger rückfrageintensive Nutzung projektbezogen einstellbar machen.

## Ergebnis
Stufenbeschreibung, sichere Voreinstellung, sichtbarer Status und Widerruf.

## Fertig, wenn
- Gefährliche Aktionen unabhängig von Stufe klar erkennbar sind.
- Änderungen von Nutzer und Zeitpunkt nachvollziehbar sind.

## Schutz
Kein stiller gefährlicher Standard; Systemschutz kann nicht übergangen werden.

## Skill
Global einen Android-Agent-Berechtigungs-Skill suchen; Quelle, Lizenz und Sicherheitsdesign prüfen und Nutzer vor Installation fragen.
