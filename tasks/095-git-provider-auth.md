# Aufgabe 095 — Git-Zugang

## Ziel
Git-Zugriff mit einem vom Nutzer eingerichteten und widerrufbaren Weg ermöglichen.

## Ergebnis
Vergleich dokumentierter Zugangswege, Berechtigungsumfang und sichere Ablage.

## Fertig, wenn
- Zugriff möglichst auf erforderliche Repositories beschränkt ist.
- Nutzer versteht, dass Uploads externe Speicherung verursachen.

## Schutz
Keine privaten Schlüssel in Projektdateien oder Chats.

## Skill
Global einen GitHub-/Git-Credential-Skill suchen; Quelle, Rechte und Lizenz prüfen, Nutzer vor Installation fragen.
