# Aufgabe 118 — Freigabeverlauf

## Ziel
Nutzer kann sehen, wann eine Erlaubnis erteilt und später geändert wurde.

## Ergebnis
Lokale, verständliche Historie mit Projekt, Aktion und Zeit.

## Fertig, wenn
- Verlauf keine unnötigen Chat-/Dateiinhalte speichert.
- Widerrufe klar von bloßen Änderungen unterschieden werden.

## Schutz
Nicht als öffentliches Protokoll übertragen.

## Skill
Global einen Consent-/Datenschutz-Skill suchen; Quelle, Lizenz und Datenerhebung prüfen, vor Installation Zustimmung einholen.
