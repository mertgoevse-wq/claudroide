# Aufgabe 129 — Skills finden

## Ziel
Für jede Implementierungsaufgabe mindestens einen global auffindbaren, passenden Skill recherchieren.

## Ergebnis
Suchbegriffe, Kandidaten, Fundort, Lizenz, Kompatibilität und Begründung dokumentieren.

## Fertig, wenn
- Keine Fähigkeit nur wegen ihres Namens als sicher gilt.
- Nicht gefundene Skills ehrlich als offen markiert sind.

## Schutz
Keine Installation während der Suche.

## Skill
Global einen Skill-Discovery-Skill suchen; Suchquelle, Lizenz und Berechtigungen prüfen, Nutzer vor Installation um Freigabe bitten.
