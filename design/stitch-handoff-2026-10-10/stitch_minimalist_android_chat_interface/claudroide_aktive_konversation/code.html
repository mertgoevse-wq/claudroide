Wie implementiere ich am besten einen Foreground Service mit Coroutines in Jetpack Compose für Audioaufnahmen im Hintergrund?

ClauDroide · gerade eben

Für Audioaufnahmen im Hintergrund unter modernen Android-Versionen (API 34+) empfiehlt sich die Kombination aus einem ForegroundService mit dem Service-Typ microphone und einem gebundenen CoroutineScope.

Service-Deklaration: Deklariere android:foregroundServiceType="microphone" und POST_NOTIFICATIONS im Manifest.

Notification: Erstelle eine persistente Notification mit Stop-/Pause-Intents.

Lifecycle: Starte den Scope mit ServiceLifecycleDispatcher oder verwalte einen eigenen SupervisorJob().

AudioRecordingService.kt 
class AudioRecordingService : Service() {
    private val serviceJob = SupervisorJob()
    private val serviceScope = CoroutineScope(Dispatchers.Default + serviceJob)
    
    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val notification = createRecordingNotification()
        startForeground(NOTIFICATION_ID, notification, FOREGROUND_SERVICE_TYPE_MICROPHONE)
        return START_STICKY
    }
}
